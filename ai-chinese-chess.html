📖 玩法说明

🎮 基本玩法：点击己方棋子（绿色高亮并显示落点提示），再点击目标位置走子；红方先手。

🤖 人机对战：右上角 ⚙️ 设置 可选择对手人设、玩家执子、AI 棋力、悔棋次数。

💬 AI 聊天：右侧面板可自由聊天，或使用「分析局面 / 给我提示 / 嘲讽我 / 复盘」快捷指令。

🎬 AI 观战：顶栏切换到「AI 观战」，看两位 AI 按不同人设对弈并实时解说。

🔑 API Key：AI 聊天与"有风格"的走子需要在 ⚙️ 设置 中配置 OpenAI 兼容 API Key（仅保存在本机浏览器）。不配置也能玩，AI 会降级为本地引擎。

⚠️ 提示：若双击本文件后 API 调用失败，可能是浏览器对 file:// 页面的跨域限制，请更换支持 CORS 的服务商，或使用「启动游戏.bat」本地服务器方式。
